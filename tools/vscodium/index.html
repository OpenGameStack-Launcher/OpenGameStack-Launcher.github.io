VSCodium

Frozen in Launcher MIT

Free/Libre Open Source Software binaries of VS Code with telemetry completely disabled.

Official Website Source Repository

Role in the Game Stack

VSCodium is a community-driven, telemetry-free binary distribution of Microsoft's VS Code editor. It provides a lightweight code editor with rich extension marketplace support for GDScript, C#, Python, shaders, and JSON configurations.

Key Capabilities & Strengths

  • Zero telemetry, tracking pixels, or diagnostic profiling by default
  • Seamless language support for GDScript, C#, C++, Rust, and Shaders
  • Built-in Git diff inspection and integrated terminal
  • Vast Open VSX extension registry ecosystem
Replaces Proprietary Software

Within sovereign and telemetry-free creative pipelines, VSCodium serves as a direct open-source alternative to proprietary software.

Replaces: Microsoft Visual Studio Code Sublime Text

Project Manifest Configuration (ogs_stack.json)

Pin VSCodium to this frozen version in your project repository by declaring it inside your ogs_stack.json manifest:

ogs_stack.json 
{
  "name": "MyGameProject",
  "version": "1.0.0",
  "tools": [
    {
      "id": "vscodium",
      "version": "1.143.17232",
      "category": "Code"
    }
  ]
}
