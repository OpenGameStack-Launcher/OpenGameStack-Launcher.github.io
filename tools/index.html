Tool Directory

Open-Source Game Development Stack

A curated two-tier directory of sovereign, telemetry-free creative tools for game creators. Every tool is evaluated for indie production readiness, open licensing, and long-term pipeline independence.

Tier 1: Frozen in Launcher Tier 2: Ecosystem Radar

Tier 1: Frozen in Launcher tools are pre-configured, verified, and frozen into reproducible offline archives distributed directly through the Open Game Stack Launcher.

Tier 2: Ecosystem Radar tools represent vetted open-source game development tools tracked across 2D, 3D, audio, and level design for community adoption and future launcher integration.

Engine

Game engines and runtime frameworks for scene authoring, logic scripting, physics, and multiplatform builds.

godot

Frozen in Launcher MIT

Godot Engine is a versatile open-source game engine featuring a dedicated 2D pipeline, modern Vulkan-powered 3D renderer, and an intuitive scene and node hierarchy. It supports GDScript, C#, and C++ via GDExtension, with zero licensing fees or revenue shares.

Replaces: Unity Unreal Engine

2D

Raster painting, pixel art, vector illustration, and sprite creation tools for game art production.

gimp

Frozen in Launcher GPL-3.0

GIMP (GNU Image Manipulation Program) provides raster editing, asset cleanup, texture channel manipulation, and format conversion. Equipped with GEGL high-bit-depth color processing and Python scripting, it serves as a workhorse for asset preparation.

Replaces: Adobe Photoshop

Version

  • 3.2.4 Official release page Frozen archive

krita

Frozen in Launcher GPL-3.0

Krita is an open-source painting program designed for illustrators, concept artists, and texture painters. It features sophisticated brush engines, wrap-around seamless texture mode, layer masks, color management, and frame-by-frame 2D animation tools.

Replaces: Adobe Photoshop Corel Painter Clip Studio Paint

Version

  • 5.3.3 Official release page Frozen archive
  • 5.2.15 Official release page Frozen archive

inkscape

Ecosystem Radar GPL-3.0

Inkscape is a vector design application utilizing standard SVG as its native format. It excels at authoring scalable user interface elements, heads-up display graphics, font glyphs, and resolution-independent vector illustrations for game titles.

Replaces: Adobe Illustrator CorelDRAW Affinity Designer

libresprite

Ecosystem Radar GPL-2.0

LibreSprite is a community-maintained, free and open-source fork of the last GPLv2 release of Aseprite. It provides retro sprite drawing tools, frame management, indexed color palettes, and animation playback for 2D game pipelines.

Replaces: Aseprite

  • Project homepage Source repository

pixelorama

Ecosystem Radar MIT

Pixelorama is an open-source 2D sprite editor and pixel art animation tool built with the Godot Engine. It provides onion skinning, layer management, animation timelines, custom brushes, and sprite sheet export tailored for indie game developers.

Replaces: Aseprite Pyxel Edit

3D

Polygon modeling, procedural texturing, UV unwrapping, and animation pipelines for real-time 3D assets.

blender

Frozen in Launcher GPL-3.0

Blender is the industry-standard open-source 3D production pipeline tool. It provides end-to-end tooling for polygonal modeling, sculpting, UV unwrapping, skeletal rigging, keyframe animation, procedural shader creation, and glTF/FBX export for real-time game engines.

Replaces: Autodesk Maya Autodesk 3ds Max Cinema 4D

armorpaint

Ecosystem Radar Zlib

ArmorPaint is a standalone 3D texture painting application. It allows game artists to paint PBR materials directly onto 3D models with GPU acceleration, ray-tracing support, and node-based material authoring, exporting ready-to-use textures for game engines.

Replaces: Adobe Substance 3D Painter Mari

  • Project homepage Source repository

blockbench

Ecosystem Radar GPL-3.0

Blockbench is a 3D modeling software specializing in low-poly, pixel-art textured, and voxel-inspired game assets. It features integrated texture painting, skeletal inverse kinematics animation, and clean glTF export for Godot and indie game engines.

Replaces: Cubik Studio MagicaVoxel Cinema 4D

  • Project homepage Source repository

material-maker

Ecosystem Radar MIT

Material Maker is a node-based procedural texture generation and 3D model painting tool built on Godot. It enables technical artists to design seamless PBR materials using procedural noises, patterns, and filters, exporting maps directly for real-time game engines.

Replaces: Adobe Substance 3D Designer

Digital audio workstations, waveform editors, and procedural sound effect generators for game soundscapes.

audacity

Frozen in Launcher GPL-3.0

Audacity is an accessible multitrack audio editor for recording live dialogue, trimming and normalizing sound effects, removing background noise, and exporting game-ready audio assets in OGG, WAV, and MP3 formats.

ardour

Ecosystem Radar GPL-2.0

Ardour is a professional-grade digital audio workstation designed for audio recording, multi-channel mixing, and mastering. It offers sample-accurate editing, flexible routing topologies, surround sound panning, and video timeline synchronization for game scoring.

LMMS is an open-source digital audio workstation for creating music and game soundtracks. It includes synthesizer plugins, beat and bassline sequencers, piano roll editing, automation tracks, and VST instrument support for indie game musicians.

Ecosystem Radar MIT

sfxr (and its web counterpart jsfxr) is a procedural 8-bit sound synthesizer created by Tomas Pettersson for rapid sound design. It generates pickups, explosions, laser shots, and jump effects with one-click randomization and waveform export.

Level Design

Tilemap editors, brush-based level authoring, and environmental layout tools designed for level pipelines.

ldtk

Ecosystem Radar MIT

LDtk (Level Designer Toolkit) is a modern 2D level editor created by Sebastien Benard, lead designer of Dead Cells. Built specifically for indie game developers, it features auto-layer tiling rules, entity definition schemas, multi-world layouts, and native Godot importer plugins.

Replaces: Proprietary Level Editors Tiled

  • Project homepage Source repository

tiled

Ecosystem Radar GPL-2.0

Tiled is the industry-standard general-purpose 2D tile map editor with over a decade of production use across commercial and indie hits. It supports orthogonal, isometric, and hexagonal grids, terrain brushes, object layers, and custom collision polygon markup.

Replaces: Commercial Map Editors

Links

  • Project homepage Source repository

trenchbroom

Ecosystem Radar GPL-3.0

TrenchBroom is a modern, responsive 3D level editor tailored for retro shooters and boomer shooters. Using brush-based CSG geometry and entity definition files, it integrates directly with Godot via the Qodot and func_godot plugins for rapid 3D level prototyping.

Replaces: Valve Hammer Editor Radiant Worldcraft

Code

Version control utilities, telemetry-free code editors, and scripting environments for reproducible software workflows.

git

Frozen in Launcher GPL-2.0

Git tracks revision history for game source code, scripts, configuration files, and project assets. It enables branching strategies, collaborative developer merges, and atomic commit histories for indie studios and open-source contributors.

Replaces: Perforce Helix Core Plastic SCM Subversion

Version

  • 2.56.0.4 Official release page Frozen archive

vscodium

Frozen in Launcher MIT

VSCodium is a community-driven, telemetry-free binary distribution of Microsoft's VS Code editor. It provides a lightweight code editor with rich extension marketplace support for GDScript, C#, Python, shaders, and JSON configurations.

Replaces: Microsoft Visual Studio Code Sublime Text
